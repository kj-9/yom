# document-navigation-ui Specification

## Purpose

文書数と見出し数が増えても、文書ツリーとページ内アウトラインから現在位置、階層、移動先を正しく理解して操作できるようにする。

## Requirements

### Requirement: 文書とディレクトリの意味を区別する

文書ツリーは文書を通常のリンク、ディレクトリを展開可能な階層要素として公開し、見た目とアクセシブルな意味の両方で区別しなければならない（MUST）。

#### Scenario: 支援技術で文書ツリーを読む

- **WHEN** 利用者が支援技術から文書ツリーを確認する
- **THEN** 文書はリンク、ディレクトリは展開状態を持つ要素として通知され、現在文書のリンクには`aria-current="page"`が付く

#### Scenario: 文書リンクを通常操作する

- **WHEN** 利用者が文書項目をブラウザのリンク操作で開く
- **THEN** 同一画面の移動に加え、新しいタブで開く操作やリンク先の取得など通常のリンク機能を利用できる

#### Scenario: フォルダと文書の記号を見分ける

- **WHEN** 利用者が文書ツリーを表示する
- **THEN** native list markerは表示されず、フォルダには展開状態を示す三角形だけがあり、文書linkは追加の記号なしで同じ本文開始位置に揃う

#### Scenario: 深い文書treeを表示する

- **WHEN** 利用者が複数階層にnestした文書を表示する
- **THEN** 各階層のindentは狭い一定幅に保たれ、左ペイン内に文書名を読める表示幅が残る

#### Scenario: 選択中の文書のsourceを開く

- **WHEN** 利用者が本文面の外にある表示形式操作で`Source`を選ぶ
- **THEN** source表示へ切り替わり、同じ操作から`Rendered`表示へ戻せる

### Requirement: 現在文書を中心に初期展開する

JavaScriptの有無にかかわらず展開操作を利用できる構造を使用し、初期表示では現在文書の祖先ディレクトリを展開し、それ以外の大きな枝を折りたたまなければならない（MUST）。

#### Scenario: ネストした文書を直接開く

- **WHEN** 利用者がネストした文書のrouteを直接開く
- **THEN** 現在文書とその祖先が表示され、無関係な兄弟ディレクトリは折りたたまれている

#### Scenario: JavaScriptを無効にしてディレクトリを開く

- **WHEN** JavaScript無効のstatic siteで折りたたまれたディレクトリを操作する
- **THEN** 利用者は再読み込みやscriptなしでその配下の文書リンクを表示できる

### Requirement: アウトラインへ見出し階層と現在位置を反映する

ページ内アウトラインは文書の見出しレベルを階層として表現し、現在見出しとその親セクションを視覚的に判別できなければならない（MUST）。

#### Scenario: 繰り返し名を含む長文を読む

- **WHEN** 複数の上位セクションが同名の下位見出しを持つ文書を表示する
- **THEN** 各下位見出しは親セクションとの階層関係が分かる位置に表示される

#### Scenario: 文書をスクロールする

- **WHEN** 現在見出しがスクロールに応じて変わる
- **THEN** 対応するアウトラインリンクは現在位置として強調され、その祖先も所属セクションとして判別できる
